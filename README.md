# Rodeo Drill Designer

Touch-first animated drill playbook for horseback rodeo drill teams.

Designed around multi-line arena choreography: draw routes with a finger or mouse, assign horses to each line, add timed holds, and play every route together as an animated team drill.

## Core workflow

1. Create a drill.
2. Add a line and choose its horse count.
3. Draw the first movement path directly on the arena.
4. Add timed holds where needed.
5. Continue drawing the line until its exit.
6. Add additional lines/routes.
7. Press Play to watch the full drill run simultaneously.

The initial arena preset is tailored to the San Antonio Rodeo grand-entry use case for the Jack Sellers Bexar County Palomino Patrol and Drill Team.
